# Contributing

This repository is primarily a portfolio and educational lab project.

If extending it:

1. Keep experiments inside isolated or explicitly authorized environments.
2. Document the exact traffic-generation command used.
3. Preserve evidence and hashes where appropriate.
4. Avoid committing raw credentials, tokens, private logs, or unnecessary PCAPs.
5. Explain detection logic and expected results.
6. Update the README and relevant incident/detection documentation.
